# Salon and Spa Management System (SAS) - Backend Server

This directory contains the Express.js backend server.

## 💻 How to Run in Terminal

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# OR
node server.js
```

Backend API Base URL: **`http://localhost:5000/api`**
Database requirement: MySQL database `sas_db` loaded with `database/schema.sql` and `database/seed.sql`
